# SvelteKit Node IPX Example

This example uses `ipxProvider({ path: '/_ipx' })` so the rendered HTML points at URLs like:

```txt
/_ipx/f_webp,q_72,w_1100/https%3A%2F%2Fimages.unsplash.com%2F...
```

The current library ships the pure URL builder only. A production SvelteKit Node deployment must provide an endpoint at `/_ipx/[...path]` that validates the source, performs the image transformation, sets cache headers, and streams the optimized bytes.

Recommended wiring for a later endpoint:

1. Add `src/routes/_ipx/[...path]/+server.ts`.
2. Parse the modifier segment and source segment generated by `ipxProvider`.
3. Reuse the same `domains`, `remotePatterns`, and `localPatterns` policy configured for components.
4. Use a server-only optimizer such as IPX/unjs or Sharp in that endpoint only.
5. Set immutable cache headers for deterministic provider output.
